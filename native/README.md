# Historical native host (1.3.x)

This directory is retained for development history only. Sentence 1.4.0 and
later run audio generation in the browser and do not load or install this host.
Do not run `install.ps1` to set up the current release.

The old host tests and `scripts/probe-audio.py` are not part of current release
verification. See [current speech setup](../docs/SPEECH.zh-CN.md).
