# Versevia · 句途 v1.5.3

让想看的视频，变成看得懂的内容。

Versevia 首次在 GitHub 发布：为桌面 YouTube 提供双语字幕、按句回听和可选的 AI 语义断句。原文与译文同屏，翻译服务由你选择。

## 下载与安装

1. 下载本页附件 **versevia-extension.zip** 并解压。GitHub 自动生成的 **Source code** 是开发源码，不能直接作为扩展加载。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的文件夹。
3. 刷新 YouTube 视频页，点击播放器中的 Versevia 字幕按钮，选择字幕来源。
4. 在 **Providers** 中连接自己的翻译服务，并将目标语言改为所需语言。初始翻译引擎关闭，默认目标语言为西班牙语。

支持 Chrome 116+ 及具备对应 Chromium 功能的桌面 Edge。无需 Node.js、Python 或本地辅助程序。附件 **versevia-extension.zip.sha256** 提供安装包校验值。

## 主要功能

- 双语、仅原文、仅译文三种阅读方式，支持作者字幕和 YouTube 自动字幕。
- 使用 ← / → 按句跳转，保持当前播放或暂停状态。
- 可选 AI 语义断句、上下文翻译与长句语块对齐。
- 支持 DeepL、Google、Microsoft、MyMemory、LibreTranslate、DeepSeek、Gemini、OpenRouter 和自定义 AI 端点。
- 自定义主题、字体、颜色、字幕位置和大小。
- 实验性语音字幕生成，需用户明确启动并配置语音识别服务。

## 本版修复

- 修复授权弹窗等待期间切换服务商导致端点与凭据混用的问题。
- 修复旧录音任务迟到的进度或结果覆盖新任务的问题。
- 录音上传前再次检查取消状态。
- 加强构建清理、版本一致性和打包检查，附带 SHA-256 校验文件。

## 已验证与限制

- 本地构建、语法检查、166 项 JavaScript 测试和 4 项 Python 打包测试通过；安装包完整性、图标路径与 SHA-256 已核验。
- GitHub Actions 在 Windows/Linux、Node.js 22/24 上执行相同发布检查，可在仓库 **Actions** 查看结果。
- 本次发布准备未执行新的真实 YouTube 安装扩展端到端测试，也未调用付费 AI/语音服务；演示截图使用预设字幕和译文。
- SABR/语音字幕属于实验性功能，依赖视频音轨、当前会话与服务商。Shorts、直播、移动端和嵌入播放器不在支持范围内。
- 扩展按 MIT 许可免费提供，不附带 API 密钥或服务额度；翻译、语义断句和语音识别可能产生服务商费用。

**English:** First public GitHub release of Versevia, a YouTube bilingual subtitle extension with sentence navigation, optional AI segmentation, configurable providers and customizable appearance. Download **versevia-extension.zip**, extract it, then load the folder containing `manifest.json` through Chrome/Edge's **Load unpacked** option. Chrome 116+ is required. Bring your own provider credentials; provider charges may apply. Speech generation is experimental. This release preparation did not include a fresh installed-extension YouTube end-to-end test or live paid AI/ASR calls. See the [English guide](https://github.com/JianuoZhu/versevia/blob/main/docs/USER_GUIDE.en.md).
